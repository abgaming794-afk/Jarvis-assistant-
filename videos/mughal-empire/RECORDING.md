# Recording sheet — Mughal Empire demo (74 lines, ~3.5 min)

Har line chhoti hai (≤5 sec) taaki har 3–5 second mein naya scene aaye. **Har line ke baad 2 second chup rahiye** — wahi scene ka cut ban jayega.

## Kaise record karein
**Tareeka A (recommended):** sab lines ek hi file mein, isi kram mein. Har line ke baad 2 second chup. File: `demo_full.m4a` (ya mp3/wav). Main khud kaat kar s01, s01b, s02 … bana dunga.

**Tareeka B:** har line alag file, naam ID se: `s01.m4a`, `s01b.m4a`, `s02.m4a` …

Tips: shaant kamra, phone munh se ~20 cm, poori recording ek hi jagah. Raftaar ~160 shabd/min. `[tags]` sirf andaaz batate hain, bolne nahi hain. `…` par chhota pause. Galti ho to wahi line dobara bol dijiye aur mujhe line ka ID bata dijiye.

Bhejne ka tareeka: file is chat mein upload kar dijiye, ya repo mein `videos/mughal-empire/audio/own/` mein push kar dijiye.
